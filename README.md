# Personal Portfolio Website — Assignment 2

## About the Website

This is my personal portfolio website created for Assignment 2 using HTML, CSS, and JavaScript.

The website introduces me as a junior Computer Science student and shares my projects, skills, and interests. It also includes interactive features to make the website easier to explore.

## Projects

### SCC – Smart Solar Cleaning System

A smart solar panel cleaning system designed to reduce dust accumulation on solar panels. It uses a dust sensor to detect when cleaning is needed and automatically activates a cleaning mechanism. The goal is to make solar panel maintenance easier and reduce the need for manual cleaning.

### Plant Care App — Prototype

A mobile application prototype designed to help people grow and care for plants, especially in Saudi Arabia.

The prototype includes gardening preferences, planting recommendations, a plant catalog with care information, and educational content about Saudi agriculture. The website also displays screenshots of the app's wireframes.

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the navigation buttons to explore the website.

No additional libraries or installations are required.

## Contact Form

The contact form checks that the name, email, and message fields are completed and that the email address has a valid format.

After validation, it opens the user's email application with a prepared message. The website does not send emails automatically.
